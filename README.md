# 离岸工具包

一个打开网页就能使用的内容创作工具集合，支持文章转换、Markdown 排版、封面制作和二维码处理。

**在线使用：[打开离岸工具包](https://stanlll-cloud.github.io/creator-tools/)**

## 可以做什么

- **文章转文档**：粘贴公开网页或 X 文章链接，读取正文，导出 PDF、可编辑 PPTX 或 Keynote 兼容文稿。
- **公众号排版**：30 套主题、富文本智能粘贴、代码高亮、多端预览、滚动同步、点击定位、公众号复制、HTML / PDF 导出。
- **X 排版**：输入 Markdown，复制富文本，支持逐张复制图片或打包下载原图。
- **封面制作**：修改标题、字体、配色和素材，导出文章封面。
- **二维码**：将链接或文字生成二维码，也可上传二维码图片进行解析。

## 怎么使用

1. 打开网站，选择需要的工具。
2. 粘贴文章链接或 Markdown；默认不自动插入图片，配图由用户自行添加。
3. 核对预览中的正文，按需修改。
4. 点击复制或下载，即可使用。

PDF 和 PPTX 共用 A4 排版，连续图片会按比例拼排。Keynote 选项下载 `.pptx`，用苹果 Keynote 打开后可保存成 `.key`。

## 使用提示

- 部分网站需要登录或限制访问，可能无法提取；可以手动补充正文和图片。
- 目标编辑器可能过滤粘贴的图片，可逐张复制原图或下载图片后上传。
- 公众号直接发布草稿需要另外配置公众号接口；目前没有收费、会员或自动发布功能。

## 本地运行

下载项目后，双击 `启动工具箱.command`，打开本地页面即可。更新提取后台和部署配置请查看 `开发说明.md`。

开源许可证见 `LICENSE`，组件许可证见 `vendor/`，来源与修改说明见 `开发说明.md`。

新版排版器源码位于 `formatter-source/`，构建产物位于 `formatter/`。进入源码目录运行 `npm install` 和 `npm run build` 可重新构建。基于 Raphael Publish 的 MIT 许可源码修改，许可保存在该目录；原有工具的许可证保留。
